SKILL
My skill is related to research/learning. I find that I often use AI to help me learn about new areas and I’ve learned to spot mistakes that AI makes that often hinder my ability to understand the idea or be confident in the result it returns. When learning something new there are often related ideas that branch off of the current topic and can help build a more concrete understanding of the practical use of the idea being discussed, that I may not be aware of, having an AI recommend these ideas is something that is missing from most of my conversations.  I’ve also noticed that AI tends to return outdated or sometimes poorly supported results without letting the user know that these results are still unverified. An additional feature I added is a structured summary file that contains the main ideas of the conversation and sticking points the user had when exploring the topic. My skill aims to fix these two problems.

Installation
	
Install the skill by adding it to a folder called .agents in your user profile for example my path is 
C:\Users\iansa\.agents\skills\research-skill
Codex should automatically detect the skill, if not restart your app.
Verify the installation by navigating to settings->plugins->skills.


MCP Server
My mcp server builds off what I created for my skill, it adds the summary docs to a vector database, this allows me to quickly find these documents and also avoids me having to dump multiple summary files into the ai’s context window to find what I am looking for.
